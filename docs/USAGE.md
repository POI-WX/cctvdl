# 使用指南 / Usage

本指南介绍 cctvdl 的完整使用流程。安装见 [README](../README.md)，遇到问题见 [常见问题](FAQ.md)。

总体流程：**导入链接 → 找到想要的视频 → 选择清晰度 → 下载 → 在下载页查看进度**。

## 📥 1. 导入内容

1. 在浏览器打开你想下载的央视栏目页、节目页、新闻文章视频页、单个视频页或央视新闻移动端视频页，复制地址栏里的链接。
2. 打开 cctvdl，在首页顶部的导入栏粘贴链接并回车；也可以直接把链接拖放到窗口。
3. 导入成功后，内容会出现在左侧列表，已导入的内容下次启动会自动保留。

**支持哪些链接**：普通栏目按月份查看；电视剧、纪录片和 4K 的节目概览页或任意一集页面都会显示全部选集，不需要切换月份。电影、新闻文章中的视频、导视和精彩片段会加入「📌 单个视频」。央视新闻视频页（地址中含 `snow-book` 和 `item_id`）可能有多条视频，导入后会全部加入这个列表。

**单个视频**：若链接是不属于常规栏目或节目集的独立视频，会被自动识别并加入左侧「📌 单个视频」集合——点该集合即可预览封面、简介与完整时间，点「下载此视频」即可下载；悬停行尾 🗑 可移除，集合同样持久保留。

![单视频直链下载](assets/single-video.png)

**管理内容**：把鼠标移到某个栏目或节目集上，右侧会出现两个按钮——

- **⭐ 收藏** — 点亮后该内容置顶到「收藏」分组（最近收藏的在最上）；再点取消。
- **🗑 删除** — 删除该内容（也可右键，或选中后按 `Delete` 键；macOS 用 `Delete` 或 `Fn+Delete`）。

内容超过 3 个时顶部会出现搜索框；表头的 `↓` 从 JSON 文件导入备份、`↑` 导出备份、`🧹` 一键清空全部内容（带确认）。

![首页](assets/home.png)

## 🔍 2. 浏览与搜索

- 点击左侧内容名称即可加载视频列表。普通栏目可以切换月份；节目集会直接列出选集。已下载的视频右侧会显示 ✓。
- 栏目列表默认从早到晚显示；节目集会逐页读取并立即显示已获取的选集和数量，并可在「正序（最早在前）」和「倒序（最新在前）」之间切换。切换月份后，之前勾选的视频不会丢失；某个月没有视频时，月份旁会出现橙色圆点。
- 用顶部搜索框按标题 / 简介 / 日期过滤。
- 点击视频行可在右侧查看封面、简介和时间；点击右侧的大封面可以放大查看，也能一键复制标题或简介。

![大图预览](assets/lightbox.png)

## 🎚️ 3. 选择清晰度并下载

1. 勾选要下载的一个或多个视频（`Ctrl+A`、macOS `⌘A` 可全选）。
2. 在设置中选择清晰度，再点「下载选中」。一次下载多个视频时，会先显示数量、清晰度和保存位置，确认后任务才会进入队列。
3. 栏目还可点「**下载本月**」一键下载当前栏目本月全部期数；它不受搜索过滤或其他已勾选视频影响。节目集和单个视频可用「下载此集/视频」或勾选后「下载选中」。

**一次下载多个栏目的视频**：可以先在不同月份、不同栏目各勾选几条，最后点击一次「下载选中」。底部会显示总数和当前列表的子计数；点「查看已选」可检查全部条目并逐条移除。切到「📌 单个视频」时，这些勾选会清空。再次点击「下载选中」会把新任务接在原任务后面，不会打断正在下载的内容；已在队列中的视频会自动跳过。

常规央视节目可选以下清晰度。不同节目实际提供的档位不同，没有对应档位时会自动选择接近的可用画质；央视新闻视频则以原页面提供的画质为准：

| 档位 | 大致分辨率 |
|------|-----------|
| 流畅 | 270p |
| 标清 | 360p |
| 高清 | 720p |
| 超清 | 720p（更高码率） |
| 蓝光 | 1080p |
| 自动 | 取当前节目可用的最高档 |

**同时下载多个视频**：在设置中把「同时下载视频数」调为 2 或 3，可以缩短批量下载时间。网络或电脑性能一般时，建议设为 1 或 2。

## 📊 4. 查看进度与管理任务

下载页把任务分为三组（可折叠）：**进行中** / **已完成** / **失败·取消**。

- **进行中** — 每张卡片显示状态、速度、剩余时间与进度；可单独「取消」，或用顶部「全部取消」。排队中的任务可通过卡片右上角的「↑ 置顶」按钮调整顺序，也可拖拽左侧 `⠿` 句柄自由排序。
- **已完成** — 卡片提供两个操作：
  - **▶ 播放** — 用系统默认播放器打开视频。借此可立即确认下载是否成功、能否正常播放。
  - **📂 文件夹** — 在文件管理器中定位该文件。
  - 下载完成的视频以 **MP4** 保存到设置中的保存目录。
- **失败·取消** — 点「↺ 重试」即可继续下载，已经完成的部分不会重复下载；顶部「重试失败」可以一次重试全部失败任务。应用意外退出后，未完成任务会在下次启动时自动恢复。

顶部还有「清除已结束」和「打开文件夹」。「清除已结束」会移除已完成、失败和已取消的卡片，不会影响已下载的视频或下载历史。下载过的视频会被记录，再次选择时会自动跳过；如需重新下载，可在设置的下载历史中操作。列表为空时，点击「**去首页选择视频**」可返回首页。一次下载结束后，右下角会显示结果；窗口最小化或隐藏时也会收到系统通知。

**侧边栏实时状态**：下载进行时，左侧导航栏下载图标下方显示迷你进度条，侧边栏底部状态区显示实时总速度；折叠状态下均可一眼感知进展，无需切换到下载页。

## ⚙️ 5. 设置

![设置](assets/settings.png)

| 设置项 | 说明 |
|--------|------|
| 视频保存目录 | 下载的视频文件将保存到此目录（需有写权限） |
| 图片保存目录 | 下载的封面图片将保存到此目录，默认为系统图片文件夹 |
| 下载线程数 | 单个视频可同时处理的下载数；数值更高不一定更快，默认 8，范围 1–16 |
| 同时下载视频数 | 同时下载几条视频（1–3）；一般建议不超过 2 |
| 视频清晰度 | 默认清晰度；原视频没有该档时会自动选择接近的档位 |
| 合并方式 | 默认「无损快速」（画质无损、速度快）；个别片源播放异常时可切「兼容重编码」 |
| 下载完成后打开文件夹 | 「下载本月」或单视频下载完成后，自动打开保存目录 |
| 剪贴板自动导入 | **默认关闭**。开启后复制已支持的央视栏目、新闻或移动端视频链接时弹窗提示导入 |
| 深色模式 | 浅色/深色切换，下次启动自动恢复 |
| 主题色 | 6 种预设主题色，即时生效 |
| 日志级别 / 日志目录 | 日志详细程度（**日常** / **调试**）与存放位置；排查问题时切到「调试」会记录更多细节 |
| 下载历史 | 查看或管理已下载记录；支持关键词搜索、单条「↺ 重新下载」、定位文件与删除；清空后已下载标记同步消失 |

## 🎨 界面图标

| 图标 | 含义 |
|:---:|------|
| 📺 | 左上角图标，点击查看「关于」与版本；有新版本时图标旁显示红点 |
| 🏠 / ⬇️ / ⚙️ | 首页 / 下载 / 设置 |
| ▶ | 播放（用系统播放器打开） |
| 📂 | 在文件管理器中定位文件 |
| ↺ | 重试失败任务；下载历史中点击可重新下载 |
| ⏹ | 全部取消 |
| ✓ / ✗ | 已完成 / 失败（任务状态）；视频行右侧淡绿 ✓ 表示已下载 |
| 📋 / 📄 | 复制标题 / 复制简介 |
| 🖼 | 支持保存视频封面 |
| 🔴 | 栏目名旁红点：该栏目有未下载新视频（点击栏目后自动消除） |
| ⠿ | 下载排队卡片左侧拖拽句柄，拖动可调整下载顺序 |
| ↑ 置顶 | 下载排队卡片右上角按钮，点击将该任务移到队列最前 |

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `1` / `2` / `3` | 切换 首页 / 下载 / 设置 |
| `F5` | 在首页刷新当前栏目的视频列表（需已选择栏目） |
| `Ctrl+A`（macOS `⌘A`） | 全选 / 取消全选视频 |
| `Ctrl+\`（macOS `⌘\`） | 折叠 / 展开左侧边栏 |
| `Delete` | 删除选中的栏目（焦点不在输入框时；macOS 也可用 `Fn+Delete`） |
| `Esc` | 关闭弹窗（封面大图、关于） |

## ✨ 更多体验

- **侧边栏**可展开 / 收起（顶部箭头按钮或 `Ctrl+\` 快捷键切换）；下载进行时下载图标下方显示迷你进度条，侧边栏底部状态区显示实时总速度，折叠状态下均可见。
- **深色模式 / 主题色**在设置中切换，下次启动自动恢复。
- **系统托盘**常驻并显示下载进度；单击托盘图标显示窗口，右键弹出菜单（Linux 个别发行版只能用菜单）；有任务失败时托盘会标注提醒（macOS 菜单栏图标显示 ⚠，其他平台 tooltip 显示失败数量），5 秒后自动消失。
- **窗口大小与位置**会被记住；重复启动会自动聚焦已打开的窗口。
- 支持把链接**直接拖拽**到窗口快速导入。

## ℹ️ 关于与版本

点击左上角的 📺 图标可打开「关于」弹窗，查看当前版本号——反馈问题时附上版本号会更便于定位。若检测到新版本，弹窗内会出现「发现新版本 vX.Y.Z，点击前往下载」链接（含具体版本号），点击即跳转到 Releases 页面（仅提示，不自动下载）。
