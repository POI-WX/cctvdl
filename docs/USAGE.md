# 使用指南

安装请看 [README](../README.md)，遇到异常可查 [常见问题](FAQ.md)。

使用顺序是：**导入链接 → 浏览节目 → 选择并确认下载 → 查看队列**。发布版已包含下载组件，无需额外安装工具。

![首页：栏目浏览与视频预览](assets/home.png)

## 先了解：可以导入什么

把浏览器地址栏中的完整链接粘贴到首页输入框，按 Enter 或点击「导入」；也可以直接把链接拖到窗口中。

- **栏目**：例如新闻联播。按月份浏览，可下载本月、指定起止月份批量下载，或跨月份挑选。央视中途更换过栏目 ID 的长期节目会合并到同一个栏目。
- **专辑**：带有选集的电视剧、有限集数的纪录片、4K 选集等。识别出所属专辑后，显示整组选集，不需要选择月份。
- **具体视频页**：程序先核对它是否属于有效栏目或专辑；能够确认时打开所属节目，电影、新闻文章视频及无法确认归属的独立片段才进入「📌 单个视频」集合。
- **央视新闻移动端视频**：支持央视新闻 App 或移动端分享出的可播放视频页；页面包含多条视频时会一并加入「单个视频」。

也支持 `v.cctv.com` 的节目目录链接。开启「加载节目看点和片段」后，央视接口返回的正片、看点和片段会按发布时间排列，并用不同颜色的标签区分；`v.cctv.com` 历史目录目前没有对应的扩展内容接口。

导入过的栏目、专辑和单个视频会保存在本机，下次打开仍在。已经导入的同一内容不会重复添加。

## 1. 浏览内容

### 栏目：按月份找节目

点击左侧栏目名称，选择月份后即可浏览该月节目。列表按从早到晚排列；可用月份旁的 `‹` / `›` 切换相邻月份，或用 `⏮` / `⏭` 一键定位最早 / 最新节目月份。停更栏目或跨度很长的历史栏目不必逐月查找。也可在搜索框按标题、简介或日期筛选。

粘贴某一期的具体视频页后，如果程序已确认它属于栏目，导入结果会显示**栏目名称**，而不是该期标题。打开栏目并切到视频日期对应的月份；若该视频是短片段，在设置中开启「加载节目看点和片段」并保存，返回首页后当前列表会刷新。

![栏目片段与类型标签](assets/column-fragments.png)

部分历史节目在播出期间更换过央视栏目 ID。遇到这类内容时，程序会使用稳定的节目归档作为数据源：无论粘贴节目概览、变更前的一期还是变更后的一期，都会进入同一个按月栏目，新旧内容不会被拆成两项。

- 「下载本月」使用当前栏目、当前月份加载完成的全部视频，不受搜索条件或其他月份已选项影响。开启片段开关后，该月列表中的片段也在此范围内；已下载或正在队列中的视频仍会跳过。
- 勾选框用于挑选当前列表中的视频；已勾选内容在切换月份、栏目、单个视频集合或修改搜索条件后仍会保留，可统一点击「下载选中」。底部同时显示已选总数和当前列表已选数。
- 已选清单为空时，底部可直接选择「按月份下载」；已有选择时，从「更多下载方式」菜单进入，不会清掉现有选择。
- 点击刷新按钮或按 `F5` 会重新读取当前列表；部分节目归档使用短期缓存，手动刷新会跳过该缓存。
- 若出现「视频列表加载失败」，点击列表中的「重试」；这与「该月份暂无视频」是两种不同状态。
- 行尾的 ✓ 表示该视频已下载。

### 跨月份整批下载

在按月浏览的栏目中打开「按月份下载」，选择起始和结束月份；「全部月份」会填入该栏目的最早和最新月份，不会立即查找或下载。专辑不提供此入口。

点击「查找视频」后，应用逐月读取列表并显示进度和找到的视频数；「取消查找」不会创建下载任务。若某些月份加载失败，先点「重试失败月份」，不能把失败月份当作空月直接入队。查找完成后核对找到、已下载和待加入的视频数，以及预计大小、磁盘剩余空间、节目内容、清晰度和保存位置；展开「查看视频列表」可检查内容，再点「加入队列」。大量任务会再次要求确认。已入队的任务照常支持队列管理和断点续传。

| 选择月份 | 核对下载内容 |
|:---:|:---:|
| ![设置栏目起止月份](assets/month-range-picker.png) | ![核对跨月份下载内容](assets/month-range-review.png) |

### 专辑：从节目首页或任意一集进入

专辑不需要选择月份。打开后会按央视返回的内容总数逐页加载，并显示已加载数量；列表加载完成后即可浏览选集。选集很多时可能需要稍等。

可在列表上方切换「从早到晚」和「从晚到早」。专辑不显示「下载本月」，可下载单集或勾选后批量下载。

![专辑浏览](assets/album.png)

### 单个视频：统一放进一个集合

导入独立视频后，点击左侧「📌 单个视频」即可查看。这里和栏目、专辑一样支持预览、勾选和批量下载；点击预览区域的「下载此视频」可以直接下载当前视频。

单个视频集合可用标题栏的导入、导出按钮备份或恢复内容；悬停视频行后点击删除按钮，可将该视频从集合移除。

![单个视频下载](assets/single-video.png)

### 收藏、删除与备份

把鼠标移到左侧栏目或专辑上：

- 点 ⭐ 将其收藏并置顶；再次点击取消收藏。
- 点 🗑 删除这一项。也可右键，或选中后按 `Delete`（macOS 可用 `Delete` 或 `Fn+Delete`）。
- 「我的内容」标题右侧提供导入、导出和清空按钮；清空栏目与专辑前会要求确认。

## 2. 预览、选择和整理

点击一条视频，右侧会显示封面、标题、简介、发布时间、频道和时长（以央视接口实际提供为准）。可直接复制标题或简介，也可把封面保存到本地；点击封面会打开大图预览。简介较长时可在简介区域内滚动，右下角的「下载此集 / 下载此视频」按钮会保持可见。

| 封面大图预览 | 已选内容 |
|:---:|:---:|
| ![封面大图预览](assets/lightbox.png) | ![已选内容](assets/selected-videos.png) |

勾选一条或多条视频后，底部会显示已选数量：

- 「查看已选」会列出所有已选视频；每行右侧的 `×` 是**移除该视频**，不是错误提示。
- 「清空已选」会取消全部勾选。
- `Ctrl+A`（macOS `⌘A`）可全选或取消全选**当前列表的筛选结果**，不会改变其他月份或栏目的已选项。

「查看已选」按来源和月份整理清单；切换到「单个视频」后仍可继续勾选，与此前的栏目、专辑视频一起下载。下载前的已选清单只在当前应用会话中保留；已加入队列的任务则会在重启后恢复。

## 3. 确认并开始下载

### 下载前确认与画质

在「设置」页先确认：保存目录、视频清晰度、同时下载视频数。通常保留默认值就可以。

1. 勾选视频后点击「下载选中」，或在预览区点击「下载此集 / 下载此视频」。按月栏目还可点「下载本月」或进入「按月份下载」。
2. 下载前会显示视频数、清晰度、预计大小、磁盘剩余空间和保存位置；已选批量下载还会列出来源、月份及看点/片段数量，视频清单可展开核对。
3. 核对后点击「加入队列」；选择「返回检查」不会开始下载。

![下载前确认：预计大小与磁盘空间](assets/download-confirm.png)

大小和空间会自动换算为 B、KB、MB、GB 等单位。预计大小来自片源信息，与最终文件可能有差异。如果只能估算部分视频，显示「已知部分」并提示实际占用可能更高；全部无法估算时显示「暂无法估算」。无法检查磁盘空间时会显示「无法检查」。空间可能不足会提醒检查保存位置，仍由你决定是否继续。

选择清晰度后，程序会优先下载该档位可用的最佳画质。各档位对应的分辨率和最高码率如下：

| 清晰度档位 | 标称分辨率 | 带宽上限 |
|---|---:|---:|
| 流畅（270p） | 480×270 | 460.8 Kbps |
| 标清（360p） | 640×360 | 870.4 Kbps |
| 高清（720p） | 1280×720 | 1.2288 Mbps |
| 超清（720p） | 1280×720 | 2.048 Mbps |
| 蓝光（1080p） | 1920×1080 | 4.096 Mbps |
| 自动 | — | 最高可用 |

央视片源不一定提供所有档位：已验证的普通节目多为 720p，部分频道提供 1080p，老节目可能只有流畅和标清。表中分辨率是档位名称，不保证片源一定提供；「自动」会选择接口实际提供的最高可用流，也不承诺某个固定分辨率。

CCTV-16 会优先尝试与所选清晰度匹配的明文 HLS，以规避部分加密片源可能出现的轻微损坏；所有明文档位都不可用时，会自动回退到普通加密下载链路。两种下载方式都支持并发、重试、取消和断点续传。

<details>
<summary>画质选择的具体规则</summary>

程序会在不超过所选档位最高码率的视频流中，优先选择分辨率最高、同分辨率下码率最高的一路。如果所有视频流都超过所选档位，则使用片源中码率最低的一路，避免下载失败；这种情况下，实际画质可能高于设置。

央视新闻移动端视频使用页面自己的画质列表，对应最高码率为：流畅 600 Kbps、标清 1 Mbps、高清 2 Mbps、超清 3.5 Mbps；蓝光与自动不限制码率。选择和兜底规则相同，实际分辨率以页面提供的画质为准。

</details>

### 保存位置

默认将视频直接保存到「视频保存目录」。开启「按节目分文件夹」后，栏目和专辑的视频进入以节目名称命名的文件夹，「单个视频」仍直接保存到所选目录。跨节目混选时，确认框会分别显示各个目标位置。

```text
视频保存目录/
  新闻联播/
    某期节目.mp4
  专辑名称/
    第1集.mp4
  独立视频.mp4
```

修改保存目录或分文件夹设置只影响新任务。已入队任务、重启恢复和失败重试沿用原路径；从首页或下载历史重新发起下载则采用当前设置。旧下载历史没有节目来源记录时，重新下载会直接保存到视频保存目录。

## 4. 在下载页管理队列

下载页分为「进行中」「已完成」「失败 / 取消」三组。新加入的任务会接在已有队列后，不会打断正在下载的内容。

| 下载进度 | 排队与顺序 |
|:---:|:---:|
| ![下载管理](assets/download.png) | ![任务排序](assets/download-queue.png) |

- **进行中**：查看进度、速度和剩余时间；可取消单个任务，或使用「全部取消」。
- **排队中**：拖动 `⠿` 手柄调整顺序，或点「↑ 置顶」移到队首。
- **已完成**：可用「▶ 播放」验证视频，或点「📂 文件夹」在文件管理器中定位它。
- **失败 / 取消**：当前队列结束后，可在任务卡片上点「重试」，复用仍完整保存在本机的已完成分片。意外退出应用后，未完成任务会在下次启动时恢复。
- 「清除已结束」只会移除已完成、失败和取消的卡片，不会删除视频文件或下载历史。

下载过的视频会记录到「下载历史」，普通下载再次遇到它会自动跳过。若确实要重新下载，可在首页打开该视频预览并点「重新下载」，也可到「设置 → 下载历史」中重新下载；正在排队或下载的同一视频仍不会重复入队。

## 5. 设置建议

| 设置 | 日常建议 |
|---|---|
| 视频保存目录 | 选一个有写权限、空间充足的目录。 |
| 按节目分文件夹 | 默认关闭；开启后按节目名称分别存放，单个视频直接保存。 |
| 图片保存目录 | 保存封面时使用；不设置时使用系统默认图片目录。 |
| 下载线程数 | 默认 8；网络不稳定或电脑负载高时可调低。 |
| 同时下载视频数 | 默认 1；一般可设为 2，网络和性能都较好时再尝试 3。 |
| 合并方式 | 保持「无损快速」；只有下载完成后播放异常时才改为「兼容重编码」。 |
| 下载完成后打开文件夹 | 队列结束后打开成功下载内容的保存位置，适用于所有下载方式。 |
| 加载节目看点和片段 | 默认关闭；开启后，节目列表将同时显示正片、看点和片段。 |
| 剪贴板自动导入 | 默认关闭；复制支持的链接时询问是否导入。 |
| 日志级别 | 日常保持「日常」；排查问题时改为「调试」。 |
| 下载历史 | 查看已下载内容、重新下载、定位文件或删除记录。 |

剪贴板自动导入开启并保存后会立即检查一次；之后在首页、下载页或设置页复制支持的央视链接，都会弹出导入提示。

自动打开文件夹会等待队列中的任务全部结束，包括下载过程中追加的任务。成功文件只有一个目标文件夹时，直接打开它；分布在多个节目文件夹时，打开对应的保存目录。若本次使用了多个保存目录，每个目录打开一次；没有成功下载的文件时不打开。

| 设置 | 深色模式 |
|:---:|:---:|
| ![设置](assets/settings.png) | ![深色模式](assets/home-dark.png) |

主题色和深色模式会立即生效，并在下次打开时保留。左侧下载图标会显示任务数量与迷你进度条；侧边栏底部会显示实时总速度，无需停留在下载页也能查看状态。

「保存设置」仅在设置发生修改后启用；保存完成后会恢复为不可用状态，并在按钮旁显示保存时间。

## 6. 提醒与窗口

- 下载时可以最小化或隐藏窗口，系统托盘仍会显示下载状态；单击托盘图标可重新显示窗口。
- 批次结束时，如果窗口隐藏或最小化，受系统支持的平台会显示静音完成通知；点击通知可恢复应用并打开下载页，不会自动打开视频或目录。窗口已显示时不再额外弹出系统通知。
- 有新版本或收藏内容出现更新时，对应位置会显示红点提醒；点击后即可查看。
- 窗口大小和位置会自动记住。再次打开已在运行的 cctvdl 时，程序会直接显示原窗口，不会重复启动。
- 点击左上角的 📺 图标可查看版本信息；反馈问题时附上版本号会更便于排查。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `1` / `2` / `3` | 切换首页 / 下载 / 设置 |
| `F5` | 刷新当前栏目的视频列表 |
| `Ctrl+A`（macOS `⌘A`） | 全选 / 取消全选当前筛选结果 |
| `Ctrl+\`（macOS `⌘\`） | 折叠 / 展开左侧边栏 |
| `Delete` | 删除当前选中的栏目或专辑（输入框内不会触发） |
| `Esc` | 关闭封面大图、关于等弹窗 |

## 需要帮助？

- 导入失败、列表为空、下载被跳过：先看 [常见问题](FAQ.md)。
- 提交问题时，请提供应用版本、系统版本、复现步骤和日志；日志级别设为「调试」后可获得更多信息。
