# 常见问题

这里按遇到问题的顺序整理排查方法。还不熟悉操作时，先看 [使用指南](USAGE.md)。

## 导入与浏览

### 粘贴链接后为什么导入失败？

请复制浏览器地址栏中的完整页面链接，不要手动拼接地址。当前可导入：

- 央视官网中的栏目、节目概览、节目集任意一集和单个视频页面；
- `v.cctv.com` 中仍可通过历史接口读取的节目目录；
- 央视网新闻中带视频的文章；
- 央视新闻 App 或移动端分享出的部分可播放视频页面。

节目下架、仅限 App 观看、地区限制或央视页面改版，都可能导致解析失败。先换一条链接验证；如果多条常见链接都失败，请携带链接和日志反馈。

常规页面支持 `cctv.com`、`cctv.cn`、`cntv.cn` 及其历史频道子域名。程序按域名边界校验央视链接，名称相似但不属于这些域名的地址不会导入。

### 为什么不同年份的单集导入后是同一个栏目？

部分长期节目在播出期间更换过央视栏目 ID，但新旧节目仍属于同一个稳定归档。程序会核对归档最早、最新及当前单集的栏目 ID；确认发生过变更后，无论粘贴节目概览还是新旧任意一期，都会合并成同一个按月栏目。列表是该稳定归档中的完整内容，再按所选月份显示。

这与电视剧节目集不同：长期栏目仍显示月份选择器和「下载本月」，电视剧、有限纪录片和 4K 选集仍显示完整选集。

### 为什么粘贴一集电视剧后，显示的是整部节目？

这是正常行为。电视剧、纪录片和 4K 节目会识别为节目集：粘贴节目首页或任意一集，都会进入同一个选集列表，方便一次查看和批量下载。部分看点或导视页如果能可靠识别所属节目集，也会打开对应节目；无法确认归属的独立片段仍按单个视频导入。

### 为什么粘贴具体视频页后，导入的是栏目而不是单个视频？

程序会优先核对该视频是否属于有效栏目。能够确认时，左侧显示栏目名称；请切到视频播出日期对应的月份查找。若粘贴的是该期中的短片段，还需开启「加载节目看点和片段」、保存设置，然后重新点击栏目或刷新列表。只有央视接口实际返回的片段才能出现在节目列表；无法确认所属节目的独立视频才进入「单个视频」集合。

### 为什么没有月份选择器？为什么视频列表为空或加载失败？

- **没有月份选择器**：当前内容是节目集或「单个视频」，它们不按月浏览。
- **栏目列表为空**：该栏目在当前月可能没有节目。可点击月份右侧的 `⏮` / `⏭`，直接定位最早 / 最新节目月份；也可手动切换月份。
- **节目集仍在加载**：列表会显示加载骨架，上方提示已加载数量；加载完成后再浏览，选集很多时可能需要稍等。
- **显示「视频列表加载失败」**：这是请求失败，不代表该月没有节目。点击「重试」，或检查网络后按 `F5`。

栏目默认从早到晚显示；节目集可切换为「从早到晚」或「从晚到早」。

### 为什么节目列表里没有看点和片段？

看点和片段默认不加载，避免列表突然增加大量短视频。需要时在「设置」中开启「加载节目看点和片段」并保存，再返回首页重新点击节目或刷新列表。央视接口能返回的正片、看点和片段会用不同标签区分；`v.cctv.com` 历史目录目前没有对应的扩展内容接口。

### 我导入的内容会丢吗？可以备份吗？

正常退出或重启应用不会清除已导入内容。栏目、节目集和单个视频保存在本机；卸载应用或清理应用数据前，请先导出备份。栏目与节目集可在「我的内容」标题右侧导入 / 导出，单个视频集合也有自己的备份按钮。收藏置顶不影响备份。

### 「查看已选」里的红色 `×` 是什么？

它是**从已选列表移除该视频**的按钮，不表示下载失败。它便于在跨栏目、跨月份选择后快速删掉某一条；「清空已选」则会取消全部勾选。

### 开启剪贴板自动导入后，程序会一直读取剪贴板吗？

该功能默认关闭。开启并保存后会立即检查当前剪贴板；之后程序会定期检测是否复制了受支持的央视链接，并弹窗让你确认导入。提示在首页、下载页和设置页都有效，连续复制多个链接时会依次询问；关闭后立即停止检测。它不会自动导入其他内容。

## 下载与队列

### 文件保存在哪里？下载完成后怎样找到？

视频保存到「设置 → 视频保存目录」，格式为 MP4。下载完成后可在卡片上点「📂 文件夹」定位，也可点下载页顶部的「打开文件夹」。封面图片保存到单独的「图片保存目录」。

### 清晰度如何选择？4K 节目一定能下载 4K 吗？

「蓝光」是标称 1080p、带宽上限 4.096 Mbps 的档位；「自动」会选择央视接口实际提供的最高可用流，没有固定的分辨率上限。即使页面标注 CCTV-4K，也要以片源实际提供的画质为准，**不能保证下载到 2160p**。

节目缺少所选档位时，程序会从实际可用的视频流中选择一路继续下载，所以最终画质可能与设置不同。各档位的带宽上限和回退规则见[使用指南](USAGE.md#下载前确认与画质)。

CCTV-16 会按当前清晰度设置优先尝试可用的明文 HLS 档位，以规避部分加密片源可能出现的轻微损坏；所有明文档位都不可用时才回退到普通加密下载链路。该切换是自动完成的，不需要额外设置。

### 为什么加入下载后被跳过？怎样重新下载？

普通下载会跳过已下载的视频；正在队列中的同一视频也不会重复加入，以免产生冲突。需要重新下载时，可打开该视频的首页预览并点击「重新下载」，或：

1. 打开「设置 → 下载历史」；
2. 找到该视频后点「↺ 重新下载」。

预览区和下载历史中的「重新下载」都会绕过已下载记录，但仍不会重复加入正在排队或下载的同一视频。

### 预计大小为什么与最终文件不同？磁盘空间提醒会阻止下载吗？

预计大小来自可获取的视频流信息或片源提供的文件大小，实际传输和合并结果可能不同。确认框的「估算范围 X / Y 个」说明有多少视频算出了大小；若只估算出一部分，显示的大小**不是整批总量**。磁盘剩余空间取自保存位置所在的文件系统，无法检查时会如实显示；空间可能不足时会提醒，但仍由你决定是否继续。加入队列前还会检查保存目录是否可写。

### 取消、失败或关闭应用后，要重新从头下载吗？

通常不需要。失败或取消后点「↺ 重试」，已经下载的部分会继续使用；应用意外退出后，未完成任务会在下次启动时恢复。若选择了新的保存目录、清理过临时文件，或央视片源本身变化，则可能无法续传。

### 如何调整队列顺序？新任务会影响旧任务吗？

排队中的任务可拖动 `⠿` 调整顺序，或点击「↑ 置顶」。新任务会追加在现有队列后，不会清空或打断正在进行的任务；需要全部停止时用「全部取消」。

### 为什么没有完成通知？点击后会打开视频吗？

只有批次结束且窗口隐藏或最小化时，应用才尝试发送系统通知；macOS 在关闭窗口但应用仍运行时也可触发。Windows/Linux 关闭应用会停止当前任务，待下次启动恢复。通知是否显示还取决于操作系统和桌面环境。

点击通知会恢复应用并切到下载页，不会自动播放视频或打开保存目录。通知不可用也不影响下载结果。

### 下载速度很慢，怎么调整？

先检查网络和央视服务状态。然后可在设置中调整：

- **下载线程数**控制单条视频同时使用多少下载连接，默认 8；提高不一定更快，网络不稳或 CPU 占用高时可调低。
- **同时下载视频数**控制同时处理几条视频，默认 1；一般建议 2，网络和电脑性能都较好时再尝试 3。

海外网络或部分地区可能无法稳定访问央视视频服务器；这类限制无法由应用本身绕过。

### 下载完成却无法播放，或合并很慢怎么办？

默认「无损快速」速度快且不重新编码。若少数视频下载完成后无法播放，在「设置 → 合并方式」改为「兼容重编码」后重新下载；它更兼容，但耗时更长。仍无法播放时，请保留日志并反馈。

### 为什么提示没有可下载内容、无法获取播放地址或保存目录不可写？

- **没有可下载内容 / 无法获取播放地址**：视频可能下架、受地区或权限限制，或央视改了页面规则；换一条链接验证。
- **保存目录不可写**：在设置中选择一个本账户有写权限的目录，避免受保护的系统目录，并确认磁盘空间充足。

## 安装、隐私与反馈

### 需要额外安装软件吗？

不需要。发布版已经包含运行所需组件，下载安装后即可使用。只有参与源码开发时，才需要查看 [贡献指南](../CONTRIBUTING.md) 中的开发环境要求。

### Windows 被 SmartScreen 拦截怎么办？

安装包未做代码签名时，SmartScreen 可能提示风险。请先确认安装包来自项目官方 [Releases](../../releases)，再在提示中选择「更多信息 → 仍要运行」。

### macOS 提示“无法验证开发者”或“已损坏”怎么办？

请先确认安装包来自官方 Releases。首次打开时，在「系统设置 → 隐私与安全性」底部点击「仍要打开」。若没有该按钮，可在终端执行：

```bash
xattr -dr com.apple.quarantine "/Applications/cctvdl.app"
```

这条命令只应对你确认可信的安装包使用；它会移除 macOS 对网络下载应用的隔离标记。

### 日志在哪里？反馈问题需要提供什么？

日志默认保存在应用的用户数据目录，可在「设置 → 日志目录」修改。遇到问题时，将「日志级别」改为「调试」，复现一次后提交：

- 应用版本和操作系统版本；
- 原始链接（若不便公开，可说明链接类型）；
- 具体操作、报错文字和发生时间；
- 相关日志，注意先删除本地路径等敏感信息。

可通过 [Bug 模板](https://github.com/POI-WX/cctvdl/issues/new?template=bug_report.yml) 提交 Issue。
