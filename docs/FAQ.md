# 常见问题 / FAQ

操作步骤见 [使用指南](USAGE.md)；这里收集安装与使用中的常见问题与排查。

## 🚀 安装与启动

**1. macOS 提示「无法验证开发者」或「已损坏，无法打开」？**
安装包未做 Apple 开发者签名（仅 ad-hoc 自签名），首次打开会被 Gatekeeper 拦截。两种放行方式任选其一：

- **系统设置（推荐）**：打开「系统设置 → 隐私与安全性」，在底部点击「仍要打开」。
- **终端命令**：执行以下命令清除「网络下载」隔离标记后再打开（若系统设置里没有「仍要打开」按钮，多见于旧版安装包，用这种方式）：

  ```bash
  xattr -dr com.apple.quarantine "/Applications/cctvdl.app"
  ```

> 备注：命令里的 `cctvdl.app` 是装进「应用程序」后的程序名，与版本号无关（带版本号的是下载的 `.dmg` 安装包）。终端命令仅清除 Gatekeeper 的下载隔离标记以绕过首次检查，请务必确认是从本项目官方 [Releases](../../releases) 下载后再执行；对来路不明的安装包不要这样做。

**2. Windows SmartScreen 拦截安装程序？**
同样因为安装包未签名。点击「更多信息 → 仍要运行」即可。

**3. 需要自己安装 Node 或 ffmpeg 吗？**
不需要。安装包已内置运行时与 ffmpeg，开箱即用。仅**从源码构建**时才需要 Node 22.x（见 [贡献指南](../CONTRIBUTING.md)），ffmpeg 也会随 `npm install` 自动获取。

## 🔍 导入与浏览

**4. 粘贴链接后提示「无法解析节目信息」？**
请直接复制浏览器地址栏中的央视栏目页、节目页、单个视频页或带视频的新闻文章页链接，不要手动拼接。当前支持 `tv.cctv.com` / `tv.cctv.cn` 的栏目、节目、4K/电视剧选集页面，`news.cctv.cn` / `news.cctv.com` 的新闻文章视频页，以及地址中含 `cctvnews.cctv.com` 或 `content-static.cctvnews.cctv.com`、`snow-book` 和 `item_id` 的央视新闻视频页；导视、预告、精彩片段会作为单视频导入。

**5. 央视新闻移动端视频链接提示「可能已下架或仅限 App 观看」？**
这类页面有些内容已经下架，或只能在央视新闻 App 内观看，因此可能无法导入。换一条链接试试；如果多条链接都失败，可能是央视网站调整了规则，欢迎反馈。

**6. 视频列表为空？**
这个栏目当月可能没有更新，可以切换月份再试；没有视频的月份旁会出现橙色圆点。栏目和节目集都从早到晚显示。电视剧、纪录片和 4K 节目通常会直接显示全部选集，因此不会显示月份选择器。

**7. 剪贴板自动导入是否会一直读取剪贴板？**
不会。该功能**默认关闭**；仅在「设置 → 剪贴板自动导入」开启后，程序才会定期检测剪贴板是否包含央视链接。关闭开关后立即停止读取，不留后台监听。

## ⬇️ 下载

**8. 下载的文件保存在哪里？是什么格式？**
保存到「设置 → 视频保存目录」指定的目录，格式为 **MP4**。完成后可在下载页一键打开所在文件夹。

**9. 下载完怎么确认视频没问题？**
在「已完成」卡片点「▶ 播放」，用系统默认播放器打开。能正常播放，就说明下载成功了。

**10. 最高能下到多清晰？支持 4K 吗？**
普通央视节目最高支持 **1080p 蓝光**；即使来自 4K 频道，目前也会按最高 1080p 保存。选择「蓝光」或「自动」即可尽量获取该节目提供的最高画质。不同节目提供的画质不同，没有对应档位时会自动选择接近的可用画质。央视新闻视频则以原页面实际提供的画质为准。

**11. 提示「未设置视频保存目录」/「保存目录不可写」？**
在「设置」中选择一个有写权限的目录（避免系统盘受保护目录）。

**12. 提示无法获取播放地址或没有可下载内容？**
通常表示这个视频暂时不能播放：可能已下架、受地区或权限限制，也可能是央视网站调整了规则。换一条视频试试；如果多条视频都失败，欢迎反馈。

**13. 部分视频下载失败？**
多为网络波动。程序会自动重试；失败后重试会保留已下载的部分，不会从头开始。常规央视流和央视新闻移动端视频均支持该行为。持续失败请检查网络或代理。

**14. 添加下载后视频直接被跳过，没有开始下载？**
已在下载历史中的视频，「下载选中 / 下载本月」会自动跳过（右上角会提示「跳过：XXX（已下载）」），避免重复下载。若想强制重新下载，可在设置页下载历史中找到该条目点「↺ 重新下载」，或先删除对应历史记录再重新添加。

**15. 下载很慢？**
可以在「设置 → 下载线程数」适当调高（默认 8，上限 16），但数值更高不一定更快；速度也取决于网络和央视服务器。

**16. 如何同时下载多个视频？**
在「设置 → 同时下载视频数」调为 2 或 3，批量下载时会同时进行多个视频的下载，缩短总等待时间。

**17. 同时下载视频数设置为多少合适？**
推荐 **2**。设为 3 时速度提升有限，网络不稳定时建议保持默认的 1。

**18. 合并很慢或卡顿？**
默认的「无损快速」很快。极少数片源在该模式下播放异常，可在「设置 → 合并方式」切到「兼容重编码」，速度变慢但兼容性最好。

**19. 海外访问下载失败？**
央视视频服务器可能对部分地区限流或不可达；这与本工具无关，可尝试更换网络环境。

**20. 下载页看到「已添加 N 个任务」，前一次下载会被清空吗？**
不会。新加入的视频会排在现有任务后面，之前的任务会继续下载。顶部的「X/Y 完成」会显示这一轮下载的总进度。如需全部停止，点工具栏「⏹ 全部取消」。

## 📝 日志与反馈

**21. 日志在哪里？**
默认在应用的用户数据目录下（`cctvdl.log`、失败批次 `cctvdl-failures.log`）。可在「设置 → 日志目录」自定义位置，失败日志会写到同一目录。

**22. 如何反馈问题？**
请带上版本号（关于弹窗可见）、操作系统、复现步骤与相关日志，按 [Bug 模板](https://github.com/POI-WX/cctvdl/issues/new?template=bug_report.yml) 提交 Issue。复现前可在「设置 → 日志级别」切到「调试」以记录更详细的日志；提交时注意脱敏。
